Zed 编辑器 · 汉化便携版
========================

快速开始
--------
1. 单文件版直接双击 zed.exe 即可,无需安装。
   安装版(setup.exe)安装完成后,从开始菜单或桌面快捷方式启动。
2. 首次启动会自动在本目录创建 data 文件夹,所有配置、扩展、
   数据库、日志都保存在其中。
3. 界面默认为简体中文。在设置中搜索"显示语言"
   (Display Language),可切换为 English 或跟随系统。
   内置语言包只有简体中文和英文两种。
   注:带 -zhcn 后缀的兜底版本不支持界面内切换,如需英文,
   编辑 data\config\settings.json,将 ui_language 改为 "en"。

便携特性
--------
- 所有数据都在程序所在目录的 data 文件夹内:删除 data 即完全重置,
  拷贝整个文件夹即可迁移到其他电脑。
- zed.exe 也可以单独拿出来使用(单文件版),首次运行同样会在其
  所在目录自动创建 data 文件夹。
- 若把 zed.exe 放进只读目录(如 Program Files),将自动回退到系统
  默认数据目录(%LOCALAPPDATA%\Zed)。

注意事项
--------
- exe 未签名:首次运行如遇 SmartScreen 蓝色提示,点"更多信息"→
  "仍要运行"。
- 自动更新已禁用(避免被官方英文安装包覆盖);升级请到本项目
  GitHub Releases 下载新版本,直接覆盖 zed.exe 即可,数据不受影响。
- 本构建为社区非官方版本,基于 GPL-3.0 协议的 Zed 官方源码与
  社区汉化项目(zed-i18n / zed-ZH_CN)编译,与 Zed Industries 官方无关。
